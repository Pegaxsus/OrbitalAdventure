# Hangar Orbital en Godot

Importa project.godot con Godot 4.5.1 estándar y pulsa F6 desde main.tscn o F5 para ejecutar el proyecto. Para generar el ejecutable, instala las plantillas de exportación de esa versión y usa el perfil Windows Desktop.

Godot carga automáticamente savegames/godot/latest.json junto a los ejecutables. F9 vuelve a cargar esa partida. Si todavía no existe, busca el guardado anterior de Godot en user://sector.json. F5 guarda en la nueva ubicación.

Los archivos de ship-attributes contienen masa, fuerza, casco máximo, longitud y capacidad de bodega, en ese orden.
